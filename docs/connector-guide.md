# 세일즈맵 AI 연결 가이드 — Claude · ChatGPT · Gemini

세일즈맵을 AI 어시스턴트에 연결하면, 대화만으로 CRM 조회·기록·분석을 할 수 있습니다.

> **연결에 필요한 것 단 2개**
> 1. 서버 주소: `https://mcp.ai.salesmap.kr/mcp`
> 2. 세일즈맵 API 토큰 (아래에서 발급 방법 안내)

---

## 시작 전: 세일즈맵 API 토큰 발급

1. [세일즈맵](https://salesmap.kr) 접속 → 좌측 하단 **설정**
2. **개인 → 연동 → API** 메뉴로 이동
3. **토큰 생성** 클릭 → 생성된 토큰을 복사해 둡니다

`[이미지 1: 세일즈맵 설정 > 개인 > 연동 > API 토큰 생성 화면]`

> 💡 API는 무료(Free) 또는 Professional 이상 플랜에서 제공됩니다. (Starter 플랜 제외)
> ⚠️ 토큰은 비밀번호와 같습니다 — 다른 사람과 공유하지 마세요.

---

## Claude에 연결하기

**요건**: Claude 유료 플랜 (Pro/Max/Team/Enterprise)

1. [claude.ai](https://claude.ai) 접속 → 좌측 하단 프로필 → **설정** → **커넥터**
2. **커스텀 커넥터 추가** 클릭

`[이미지 2: Claude 설정 > 커넥터 > 커스텀 커넥터 추가 버튼]`

3. 아래와 같이 입력 후 **추가**:
   - 이름: `세일즈맵`
   - 원격 MCP 서버 URL: `https://mcp.ai.salesmap.kr/mcp`
   - (고급 설정은 건드리지 않아도 됩니다)

`[이미지 3: 커스텀 커넥터 추가 다이얼로그 입력 화면]`

4. **연결** 클릭 → 브라우저에 세일즈맵 연결 페이지가 열립니다
5. 복사해 둔 **API 토큰을 붙여넣고 [연결 승인]** 클릭

`[이미지 4: 세일즈맵 MCP 연결 — 토큰 입력 페이지]`

6. 끝! Claude 대화창에서 커넥터가 켜져 있는지 확인하고 바로 사용하세요.

`[이미지 5: 연결 완료 후 Claude 대화 예시 — "이번 주 딜 정리해줘"]`

> 데스크톱 앱에서도 동일하게 설정 → 커넥터에서 추가할 수 있습니다.

---

## ChatGPT에 연결하기

**요건**: ChatGPT 유료 플랜 (Plus/Pro/Business/Enterprise) + 개발자 모드 활성화

1. [chatgpt.com](https://chatgpt.com) 접속 → 프로필 → **설정**
2. **커넥터(Connectors)** → 하단 **고급 설정** → **개발자 모드(Developer mode)** 켜기

`[이미지 6: ChatGPT 설정 > 개발자 모드 토글]`

3. 커넥터 목록에서 **만들기(Create)** 클릭 후 입력:
   - 이름: `세일즈맵`
   - MCP 서버 URL: `https://mcp.ai.salesmap.kr/mcp`
   - 인증: **OAuth**

`[이미지 7: ChatGPT 커넥터 만들기 입력 화면]`

4. **만들기** 클릭 → 세일즈맵 연결 페이지가 열립니다
5. **API 토큰을 붙여넣고 [연결 승인]** 클릭
6. 대화창에서 도구 아이콘 → 세일즈맵 커넥터를 켜고 사용하세요.

`[이미지 8: ChatGPT 대화에서 세일즈맵 커넥터 활성화]`

---

## Gemini에 연결하기

**요건**: 개인 Google 계정 (현재 Google 정책상 미국 계정 한정 — 국내 정식 오픈 시 별도 안내 예정)

1. [gemini.google.com](https://gemini.google.com) 접속 → **설정 → Connected Apps**
2. **앱 추가**에 MCP 서버 URL 입력: `https://mcp.ai.salesmap.kr/mcp`

`[이미지 9: Gemini Connected Apps 추가 화면]`

3. 세일즈맵 연결 페이지가 열리면 **API 토큰을 붙여넣고 [연결 승인]**

> Gemini 지원 지역이 확대되는 대로 이 가이드를 업데이트합니다.

---

## 자주 묻는 문제

**"토큰이 유효하지 않습니다"가 떠요**
→ 토큰 복사 시 앞뒤 공백이 섞였는지 확인하고, 세일즈맵 → 설정 → 개인 → 연동 → API에서 토큰을 다시 복사해 주세요.

**"허용되지 않은 IP" 오류가 떠요**
→ 워크스페이스에 IP 접근 제한이 설정된 경우입니다. 세일즈맵 워크스페이스 관리에서 IP 허용 목록을 확인하거나 관리자에게 문의해 주세요.

**연결은 됐는데 AI가 느리게 답해요**
→ 같은 워크스페이스에서 여러 명이 동시에 AI를 사용하면 조회 속도가 잠시 느려질 수 있습니다. 오류가 아니며 자동으로 처리됩니다.

**예전에 JSON 파일로 설정했는데 다시 해야 하나요?**
→ 아니요. 기존 설정은 그대로 동작합니다. 새 방식은 신규 연결 시에만 사용하면 됩니다.

**연결을 끊고 싶어요**
→ 각 AI 서비스의 커넥터 설정에서 세일즈맵을 제거하면 됩니다. 토큰 자체를 무효화하려면 세일즈맵에서 토큰을 삭제하세요.
